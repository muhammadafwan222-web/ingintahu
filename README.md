# 🚀 Blog Monetisasi Profesional (Template)

Template website blog modern, responsif, dan dioptimalkan untuk SEO. Dirancang khusus sebagai "kendaraan" untuk monetisasi melalui **Google AdSense**, **Link Afiliasi**, dan **Sponsored Post**.

## ✨ Fitur Utama
- **SEO Friendly**: Struktur HTML5 semantik dan Open Graph tags untuk share media sosial.
- **Super Cepat**: Tidak menggunakan framework berat (seperti Bootstrap/jQuery), murni HTML/CSS/JS.
- **Responsif**: Tampilan sempurna di Desktop, Tablet, dan Smartphone.
- **Monetization Ready**: Placeholder khusus yang sudah disiapkan untuk penempatan iklan AdSense dan box link Afiliasi.
- **Halaman Wajib**: Sudah disediakan struktur untuk halaman Privacy Policy, About, dan Contact (Syarat mutlak diterima AdSense).

## 🛠️ Cara Menggunakan Template Ini

1. **Clone atau Download** repository ini.
2. Ganti teks, gambar, dan konten di `index.html` dan `post.html` dengan artikel asli buatan Anda.
3. **Mendaftar Google AdSense**: 
   - Buka `index.html` dan `post.html`.
   - Cari komentar `<!-- TEMPAT SCRIPT GOOGLE ADSENSE -->`.
   - Paste kode script yang diberikan Google di sana.
4. **Mendaftar Afiliasi**:
   - Cari komentar `<!-- TEMPAT LINK AFILIASI -->` di `post.html`.
   - Ganti `href` dengan link referral Anda dari Shopee/Tokopedia/Amazon.

## 🚀 Cara Deploy ke GitHub Pages (Gratis Hosting)
1. Push repository ini ke GitHub Anda.
2. Pergi ke **Settings** > **Pages**.
3. Pada bagian *Branch*, pilih `main` dan folder `/ (root)`.
4. Klik **Save**. Website Anda akan live di `https://username.github.io/nama-repo/` dalam beberapa menit.

## ⚠️ Disclaimer
Template ini hanya menyediakan kerangka website (Frontend). Untuk menghasilkan uang, Anda **WAJIB** mengisi website ini dengan konten artikel original, berkualitas, dan unik. Google AdSense akan menolak website yang hanya berisi template kosong atau konten hasil copy-paste.
